# IntegrityLens — Research Website Prototype

## Research metadata used
- **Area:** Plagiarism & Academic Integrity
- **Research topic:** Analyzing Plagiarism Patterns in Literature Review Sections: Direct Copying vs Technical Paraphrasing
- **Journal context:** Journal of Information Ethics (Scopus Q2)
- **Grant context:** ICSSR Grant

## Included features
- Sign in and create-account UI (local browser demo)
- Research dashboard
- Text analysis workbench with illustrative token overlap
- Proposed 8-label pattern taxonomy
- Research report status view
- Literature review theme page
- Profile settings and light/dark mode
- Export status note

## Run
Open `index.html` directly in a modern browser. No build step is required.

## Important limitations
This is a frontend prototype, not a production authentication system. Demo credentials are stored in browser localStorage. Do not enter real passwords or sensitive manuscripts. The text analysis is a basic token-overlap illustration; it is not an actual plagiarism detection engine. No corpus, external source search, database, or empirical results are included.
