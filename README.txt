CHROMATIC — Accessible Data Visualization Website

Run:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. For easiest local preview, install the VS Code Live Server extension and click "Go Live" on index.html.
   Or open index.html directly in a modern browser.

Included:
- Sign in and create-account demo flow (browser localStorage; not production authentication)
- Overview dashboard
- Heatmap Lab with Viridis, Cividis, Plasma, Magma, Coolwarm and RdYlBu
- Typical vision, protanopia preview, deuteranopia preview
- Palette explorer
- Stylized spatial grid preview
- Report export to TXT
- Dark mode and editable demo profile

Important:
This is a front-end academic prototype. The data and accessibility index shown are illustrative, not validated clinical measures. For a real deployment, replace demo localStorage authentication with secure server-side authentication and a database. Chart.js is loaded from a CDN, so the overview chart needs internet access.
